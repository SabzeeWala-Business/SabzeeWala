# SabzeeWala

- **Mobile App:** Flutter (Android / iOS)
- **Live Admin Panel:** [https://sabzeeewala.netlify.app/](https://sabzeeewala.netlify.app/)
- **Backend API:** Node.js Express (`backend/`)
- **Database & Storage:** Supabase - Bucket: `SabzeeWala`

## Project Structure
- `/lib` - Flutter Mobile App
- `/backend` - Express.js Backend API Service (MSG91, Cashfree, FCM, Auth)
- `/web_admin` - Vite React Admin Panel deployed on Netlify
